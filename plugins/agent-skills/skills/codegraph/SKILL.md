# CodeGraph — Deterministic Code Knowledge Graph

Build and query AST-based structural relationships in codebases without expensive text grepping.

## Core Capabilities
1. **Symbol Mapping**: Index functions, methods, classes, types, interfaces, and variables with exact line definitions.
2. **Dependency & Call Chains**: Trace caller-callee relationships, imports, and cross-file dependencies.
3. **Structural Queries**: Perform graph-based navigation across files and modules deterministically.
