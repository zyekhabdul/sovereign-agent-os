# Graphify — Knowledge Graph Codebase Mapper

Transform codebases and documentation into queryable graph structures for rapid retrieval.

## Guidelines
1. **Graph Construction**: Map modules, dependencies, documentation, and data schemas into a queryable graph.
2. **AST Parsing**: Utilize language parsers to understand project topology deterministically.
3. **Graph Traversal**: Retrieve related context via node relationships rather than full-file reading.
