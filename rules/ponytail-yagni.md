# MANDATORY GLOBAL RULE: PONYTAIL / YAGNI CODE MINIMALISM

- **Principle**: "Minimalist Code Generation - Zero Over-Engineering"
- **Applicability**: ALL AI coding agents (Antigravity CLI `agy`, Claude Code, Cursor, Codex, OpenCode).

---

## 1. STRICT MINIMAL DIFF RADIUS
- AI agents MUST restrict code modifications to the exact target functions, classes, or files requested by the user.
- **Strict Prohibition**: NEVER perform unsolicited refactoring, code formatting, variable renames, or style overhauls on untouched sections of a file.

---

## 2. ZERO SPECULATIVE ABSTRACTION
- AI agents MUST NOT create helper functions, utility classes, wrapper functions, generic factories, or extra interfaces unless explicitly specified in the user request or approved `PLAN.md`.
- Always solve the immediate problem with the most direct, idiomatic, and minimal code possible.

---

## 3. PROHIBITION ON DEAD CODE & BLOAT
- Never introduce unused imports, commented-out dead code blocks, or placeholder functions.
- Every added token must serve an active, verifiable purpose in satisfying the current requirement.
